# Fetch Functions for Browser Console

Here are the JavaScript `fetch` equivalents for testing your API directly from the browser console (e.g. Chrome DevTools).

*Note: The API has CORS enabled (`CORS(app, resources={r"/*": {"origins": "*"}})`), so you won't have any Cross-Origin issues when running these from the browser.*

### 1. Analyze Image (`/api/analyze_image`)
This endpoint expects a `multipart/form-data` payload.

```javascript
async function analyzeImage(file, serverUrl = 'http://localhost:5002') {
  const formData = new FormData();
  formData.append('image_file', file);
  
  const response = await fetch(`${serverUrl}/api/analyze_image`, {
    method: 'POST',
    body: formData
  });
  
  return await response.json();
}
```

### 2. Add Face (`/api/add_face`)
This endpoint expects JSON containing a `name`, a `location` array `[top, right, bottom, left]`, and the `original_image_b64`.

```javascript
async function addFace(name, base64Image, serverUrl = 'http://localhost:5002') {
  const response = await fetch(`${serverUrl}/api/add_face`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      name: name,
      location: [0, 100, 100, 0], // Mock bounding box coordinates
      original_image_b64: base64Image
    })
  });
  
  return await response.json();
}
```

### 3. Recognize Faces (`/api/recognize_faces`)
This endpoint expects JSON containing an array of base64 encoded face images.

```javascript
async function recognizeFaces(base64Image, serverUrl = 'http://localhost:5002') {
  const response = await fetch(`${serverUrl}/api/recognize_faces`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      faces: [base64Image]
    })
  });
  
  return await response.json();
}

/* --- Usage in Console --- */

```

### 4. Analyze Image Stream (`/api/analyze_image_stream`)
This endpoint expects raw image bytes directly in the request body.

```javascript
async function analyzeImageStream(fileOrBlob, serverUrl = 'http://localhost:5002') {
  const response = await fetch(`${serverUrl}/api/analyze_image_stream`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/octet-stream'
    },
    body: fileOrBlob // Passing a File or Blob directly streams the raw bytes
  });
  
  return await response.json();
}
```
